* Minimalistic Zettelkasten minor mode for Denote

*The core idea of this package is to allow to use Denote without visual clutter that Org links and =denote:= prefixes cause when there is no rendering wanted or available. I.e. use bare Denote IDs in your notes and they act as links. This makes dealing with bare text note files more visually pleasant when used outside Emacs.*

Barezettel makes detected Denote IDs interactive. Just use =M-RET= on the ID and you will be provided with a completion list of all the notes containing the ID to pick from. This /"link as search"/ functionality might be familiar to you from [[https://zettelkasten.de/the-archive/][The Archive]] app.

To make visual experience even more endurable, lines starting with IDs are treated as if the they were bullets; hanging indents are constructed accordingly. Caveat: the hanging indent feature does not work when org-indent-mode is active.

*This package is under early stages of development. Expect breaking and sudden changes in directions it will take. Right now the development is driven by needs dictated by my personal Zettelkasten workflow.* 


Installation:

#+begin_src elisp
  (use-package barezettel
    :load-path "path/you/downloaded/this"
    :ensure nil
    :hook (text-mode . barezettel-mode)
    :bind (("C-c n x" . #'barezettel-denote-append-title-at-point)
           ("C-c n l" . #'barezettel-denote-link)
  	 ("C-c n >" . #'barezettel-forward-id)
  	 ("C-c n <" . #'barezettel-backward-id)
  	 :map barezettel-denote-id-keymap
  	 ("M-<return>" . #'barezettel-denote-show-targets-at-point))
    :custom
    (barezettel-use-brackets-around-signature t))
#+end_src
